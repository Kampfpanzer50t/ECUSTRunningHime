华理跑步姬 · Windows 电脑版 v2.1.1

一、运行
双击 huati-desktop-v2.1.1-windows-x64.exe 即可打开，无需安装 Python 或 Node.js。
适用于 Windows 10/11 的 64 位电脑。第一次启动需要几秒解压时间。

二、登录
在“账号与设置”中使用绑定的手机号和短信验证码或账号密码登录。
也可以导入手机端导出的 JSON 会话文件。会话与运行状态加密保存在当前 Windows 用户的数据目录中，不包含在程序发布文件内。

三、定时执行
在“定时计划”中选择每天 06:00–21:00 之间的开始时间，点击“保存并开启自动运行”。
程序会提前两分钟准备校内随机模拟起点，并刷新当天信息和随机三点。
若设置 06:00 开始，05:58 准备起点，06:00 接口开放后刷新三点。
随机模拟时长严格大于 12 分钟、小于 16 分钟，精确到毫秒；至少经过三点、总里程至少 2.1 公里。
计满时长后自动校验并提交，即使服务器判为无效也会提交。
今天改为稍后的其他开始时间，可以再次自动执行；服务器仍然可能判为无效。

四、后台运行
关闭主窗口会收起到系统托盘，定时与提交继续运行。双击托盘图标可以重新打开。
锁屏与最小化窗口不会停止主进程。
启用计划或模拟进行中，程序会阻止系统自动睡眠；显示器可以自动熄灭。
请保持电脑联网。主动睡眠、休眠、关机、退出程序以及强制结束进程时无法保证按时执行。
可在软件中开启“登录 Windows 后启动电脑版”。开启后请将 exe 保留在固定位置，移动文件后重新设置开机启动。
“一分钟锁屏自检”仅验证后台计时，不会创建服务器跑步记录。

五、手动模拟
刷新三点，设置里程、时长与步数，预览路线，再确认开始。
支持暂停、继续和舍弃。舍弃只停止本地任务，已经创建的服务器记录仍然保留。
沿道路生成路线时，手动路线允许与目标里程相差 0.5 公里，但实际里程至少 2.1 公里。
校园地图支持滚轮缩放与拖动，可显示历次收集或手动导入的点位；已知点位不等于服务器全部点位。

六、网络失败与状态恢复
准备失败和提交前的只读校验会继续重试。
创建、提交或轨迹上传收到不明确的响应时，显示“待核实”，不会盲目重复发送；请先在官方小程序确认实际结果。
重启软件会读取保存的计划和当前进度，仍以实际完整计时后提交。
同一账号请避免同时由手机和电脑执行自动计划。
成绩是否有效以官方校园跑服务器为准。

七、电脑起点
电脑通常没有手机 GPS，本版直接使用奉贤校区内随机模拟起点。
发布包不携带本机账号、会话、抓包文件或原手机私有数据。

验证：后台执行与核心路线的自动化测试，五个页面切换、地图缩放、资源加载和打包启动检查。
未在本次开发测试中创建真实账号的校园跑记录。

本次更新：模拟时长可分别输入分钟、秒、毫秒（例如 15 分 12 秒 345 毫秒），总时长 1–120 分钟。没有有效校内起点、三点缺失或过期时，开始模拟会自动选择校园道路随机起点并刷新三点。计时保存到毫秒，实际启动和提交仍受系统及网络调度影响。
