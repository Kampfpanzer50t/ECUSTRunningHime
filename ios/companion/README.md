# 手机锁屏时，由自己的电脑代执行

这是苹果 App 的可选助手。App 内仍可设置每日时间、查看状态、暂停、继续、舍弃和停止计划。助手按北京时间提前两分钟刷新随机三点，到点开始，计满随机 12–16 分钟后直接提交；任务由电脑处理，iPhone 锁屏不会暂停它。随机时长精确保存到毫秒，自动路线经过三点且至少 2.1 公里。不会改变服务器对有效次数的判断。

当前交付仅包含可运行助手与配置流程。没有部署公网服务、导入你的会话或启用实际计划。需要你自己的持续开机电脑或服务器。

## Windows 准备

1. 安装 [Node.js 22 LTS](https://nodejs.org/)；保留整个 iOS 工程文件夹，助手使用其中的地图与规则。
2. 电脑设置 → 系统 → 电源，把插电时睡眠设为“从不”。允许电脑联网。助手退出、电脑睡眠或网络中断时无法保证准点执行。
3. 为助手准备**自己的 HTTPS 地址**。推荐在电脑和 iPhone 安装 [Tailscale](https://tailscale.com/)，加入同一私人网络；在自己的 Tailscale 管理页启用 HTTPS，使用 Tailscale Serve 把电脑本机端口映射为仅私人网络可访问的 HTTPS 服务。不要开启公开 Funnel。
4. 在电脑终端运行：

```powershell
tailscale serve --bg http://127.0.0.1:8765
tailscale serve status
```

以工具实际显示的 `https://你的电脑.你的网络.ts.net` 地址为准。若界面提示 HTTPS 未启用，按 Tailscale 提示在自己的网络中启用。也可以自行使用带有效证书的 HTTPS 反向代理，把根路径代理到 `http://127.0.0.1:8765`；手机必须能访问这个地址。iOS 不接受明文 HTTP，助手不向公共第三方代跑服务传会话。

5. 在 `companion` 文件夹打开 PowerShell，首次运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Companion.ps1 -Endpoint 'https://你的电脑.你的网络.ts.net'
```

脚本生成 `companion/private/huati-companion-pair.json`，随后保持助手运行。以后启动无需重复初始化：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Companion.ps1
```

不要同时启动两份。异常强制结束后若提示启动失败，先确认没有其他助手进程运行，再删除**该助手 `private` 文件夹内的 `executor.lock` 文件**重新启动；保留 `state.bin` 与 `key.bin`，不要删除原记录。正常结束会清理实例锁。

## iPhone App 配对与定时

1. 先在 App “账号”页登录，并处理手机原有未完成记录。
2. 将电脑生成的配对 JSON 通过自己的文件传输方式放进 iPhone“文件”App。配对文件包含访问凭据，只放在自己的设备，不上传到 GitHub、不分享给他人。
3. App “自动 → 电脑代执行 → 导入电脑配对文件”。导入会检查 HTTPS 与配对信息是否可用。
4. 在上方选择每日时间，再点“同步以上时间到电脑并开启”。这一步把登录会话与计划通过 HTTPS 发送到**你自己配置的电脑**；电脑接管后手机本机创建停用。
5. 允许 iPhone 保持连接私人网络（使用 Tailscale 时打开其 VPN）。计划已同步后电脑执行无需手机持续联网；查看状态、改时间或暂停仍需手机连上电脑。
6. 可锁屏；之后在 App 点“刷新电脑状态”查看结果。电脑不主动向其他人发送消息。

首次计划尽量至少提前三分钟保存，以留出准备时间。已过设定时间但仍在当天允许启动窗口内，会重新准备并补启动；从实际开始完整计时。若设为 06:00，05:58 准备起点，06:00 校园服务开放后刷新三点，然后开始，无法早于接口完成创建。

电脑无法读取锁屏 iPhone 的实时 GPS，使用校内随机模拟起点。位置和轨迹是模拟数据。若准备接口失败，30 秒后重试；准备跨过计划时间后从实际启动计算，未完成准备不会使用过期三点创建。

## 暂停、继续、舍弃与切回手机

App 的电脑代执行模块展示电脑当前记录，可暂停、继续或舍弃。暂停冻结剩余时长；继续使用同一记录。舍弃停止本地模拟，服务器已经创建的占位记录保留。明确校验无效仍提交。

“停止后续电脑计划”仅关闭后续任务，已开始的记录继续处理。“结束代执行，交回手机”需电脑记录已完成或舍弃，成功确认后才能使用本机创建。结果不确定时 App 保留电脑所有权，点刷新会用原指令编号核实，避免两端重复。

创建、正式提交或轨迹上传断线/中断时保留“待核实”，不自动重发；请查看官方小程序。只读校验失败时暂停。电脑会持久保存状态，正常重启后已确认创建的记录可继续计时；暂停和待核实记录不自动恢复发送。

## 数据与运行方式

助手只监听 `127.0.0.1:8765`，需要配对令牌验证，不允许浏览器跨站指令。会话和状态以 AES-GCM 加密保存。Windows 密钥由当前用户 DPAPI 保护，只能由同一 Windows 用户解密；不要换用户运行或删除密钥。其他系统使用权限为 0600 的本地密钥文件，需自行保护该数据目录。

Node.js 22 在 Linux/macOS 也可运行：

```sh
node runner.cjs init --endpoint 'https://your-own-host.example'
node runner.cjs serve
```

即使电脑持续运行，系统定时器、网络请求与服务器处理也会带来延迟。助手在准备完成后使用毫秒定时器尽量到点执行，并按实际记录时间计时；不承诺网络请求恰好在指定毫秒完成。

离线回归检查（使用假接口，不发送真实请求）：

```sh
node --test ../Tests/core.test.cjs ../Tests/companion.test.cjs
```
